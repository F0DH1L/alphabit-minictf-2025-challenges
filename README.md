# Alphabit MiniCTF 2025

In the 2024/2025 season, I was the technical team leader at Alphabit Club, a scientific club at my university. I led the team that built a CTF for our members.

This repo has the challenges, write-ups, and deployment scripts for the CTF.

The CTF had many categories: Web Security, Cryptography, Forensics, Misc, Pwn, Reverse Engineering.

A big thanks to all the authors who helped me with challenge creation.
