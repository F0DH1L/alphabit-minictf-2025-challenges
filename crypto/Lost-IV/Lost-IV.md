# **Challenge Name:** Lost IV

**Category:** Cryptography  
**Difficulty:** Medium

---

## **📜 Description**

We encrypted a secret message using **AES-CBC mode**, but unfortunately, we **lost the IV** because it was randomly generated. 😰

The only thing we still have is:  
✅ **The encryption key** (AES-128 key)  
✅ **The ciphertext** (Hex-encoded)  
✅ **The encryption script**

Can you **recover the lost IV** and use it to decrypt the flag?

---

## **📂 Provided Files**

- `challenge.py` → The encryption script.
- `ciphertext.txt` → Contains the encrypted flag.
