# {Memory}

**`Author:`** [am1ne._b3ng](https://github.com/ma-ben10)

## Description

A notorious hacker has infiltrated a Windows machine within an organization's network. To cover their tracks, the attacker decided to leave no logs behind and instead extracted important information directly from the system's memory (RAM). However, the attacker made a small mistake while performing the attack. They accidentally left behind traces of valuable information in the RAM dump.
You, as the CTF participant, are tasked with extracting the names of the user account and the computer name of the hacked Windows machine from a captured memory dump file (memdmp.dmp).
the flag format is "Alphabit{username_machineName}"
